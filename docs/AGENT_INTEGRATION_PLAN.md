# 本地 Agent 接入实施计划

## 目标与边界

本机 Agent 通过 MCP 修改正在运行的 Electron Chrona，用户在同一画布看到结果。沿用现有 ps 时间模型、时序引擎和文件格式。Renderer 网页预览不开放系统端口。

## 实施顺序

1. 工程会话：提取统一提交入口，内存 sessionId/revision；打开工程更换会话；有界撤销/重做历史，撤销同样递增 revision。
2. 自动化领域接口：类型化创建/修改/删除、Bus、Delay、Setup/Hold、派生 Q；批次原子校验；版本冲突；请求去重；按需读取解析波形。
3. 本地 MCP：官方 SDK 的 Streamable HTTP，Electron 主进程监听 127.0.0.1 随机端口；每次启用生成凭据；受限 IPC 转发至唯一工程状态；关闭服务取消待处理请求。
4. 用户界面：Agent 连接面板、复制配置、启停、修订和操作摘要、统一撤销/重做；沿用 Mantine。
5. 验证与交付：领域与实际 MCP 客户端集成测试、构建、桌面联调、使用说明及示例。

## 一致性约定

- 所有已提交工程变更（包括手动编辑）经过同一同步提交入口。
- 写入必须携带 sessionId、expectedRevision、requestId；检查和提交不可分割。
- 成功请求重试返回原结果；同一 requestId 不允许不同内容。去重缓存有界，旧版本仍不能重放写入。
- 不保存历史工程副本到文件。内存撤销历史限制步数和总估算字节数。
- 第一版不依赖资源推送：Agent 写前读取、冲突后重读。通知无法保证模型上下文即时刷新，后续按客户端兼容性增加。
- 第一版不提供自动合并、跨会话撤销、后台启动应用或文件系统访问。

## 验收重点

手动编辑后旧请求被拒绝；重新打开后旧会话失效；坏批次零写入；重试零重复；依赖循环被拒绝；一次 Agent 批次一次撤销；主进程退出/停用后端口与挂起请求清理；真实 MCP SDK 可发现和调用工具。

## 当前结果（2026-11-01）

- 已完成 1–4：统一工程会话与 Undo/Redo、有界内存历史及请求去重、类型化批次、MCP 服务、受限 IPC、Agent 面板。
- 自动化测试 48 项通过，包含真实 MCP SDK 初始化、工具发现、写入/重试、并发冲突以及 HTTP 访问边界；生产构建通过。
- 独立 Electron 窗口经 Playwright 与真实 MCP 客户端联调：画布显示创建结果、Undo/Redo 同步、手动输入使旧修订失效、打开工程使旧会话失效、停用后端口关闭，Renderer 无运行时错误。
- 使用与接口说明见 [AGENT_API.md](AGENT_API.md)。
- 后续独立迭代：变化订阅、Bus 扩缩容、分组、图片预览、文件保存/导出及更多客户端专属配置。第一版配置使用通用 Streamable HTTP JSON，暂未逐一验证各 Agent 产品。

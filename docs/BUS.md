# Bus：基础并行数据通道

Bus 是用户定义的并行 Data Signal 集合。每条通道保留独立的 Signal ID、Pattern、Start、数据间隔以及 Timing 关系。`D0` 等符号只是数据项身份标签，不是逻辑值或整组并行字。Bus 不要求 Clock，也不推断不同 Bus 之间的转换关系。

## 创建与数据

从 `Add → Bus` 设置名称、通道数（1–256）、Start 和数据间隔。Start 与间隔沿用现有的时间单位转换组件，内部统一保存为 ps。默认规则为前缀 `D`、起始编号 `0`、通道步进 `1`、时间步进等于通道数、长度 `3`。40 路 Bus 的第 0 通道因此是 `D0 D40 D80`，第 1 通道是 `D1 D41 D81`。

新建时可在名称中输入 `data<10:4>`，自动建立 7 路，依次命名为 `data〈10〉` 到 `data〈4〉`。通道在工程中的 `busIndex` 仍是 0–6，便于保留既有排序和引用；编号只影响显示名称，不改变生成规则的通道步进。区间最多 256 路。

Bus 在信号列表和波形侧栏显示完整名称，例如 `DATA<10:4>`；工程数据中的 Bus 名称仍保存为基础名与编号范围，现有工程会按已保存的通道编号显示。建立后，在右侧 **Bus identity** 分别修改 **Bus name** 和 **First bit / Last bit**。应用编号范围时，两个端点决定顺序和宽度；缩小范围会先列出受影响的数据与引用，再让你确认。派生 Bus 只能在保持宽度的情况下重新编号。新通道名称由 Bus 统一生成，子通道属性栏的 **Edit** 链接会返回父 Bus。旧工程中已有的自定义通道名仍保留。

长度表示每条通道 Pattern 中的数据项个数。与普通 Data Signal 一致，Pattern 结束后从头循环，直到工程时长结束。每条通道的 Pattern 可以在展开后通过现有 Pattern Builder 单独编辑。

在 **Fill channel data** 选择 **Generate** 或 **Paste table**，操作范围是整条 Bus。生成规则指定前缀、起始编号、通道步进、时间步进与长度；粘贴时每行对应一个通道，列之间用制表符分隔，行数须等于 Bus 宽度。上方表格随有效输入预览结果，右上角的展开按钮可检查全部通道和时间槽。点击 **Apply to Bus** 才写入工程；默认保留局部 Pattern 修改，勾选 **Replace local pattern edits** 才会覆盖。若要编辑单路，点击预览中的通道名，在 **Edit segments** 修改。

## 默认值与覆盖

Bus 保存 Start、数据间隔及生成规则。通道可分别覆盖这三个参数；属性面板标出继承状态，并提供“Restore … default”。修改 Bus 默认值，只更新仍继承该参数的通道。缩减通道数会保留剩余通道 ID、设置和引用；删除的数据、Delay 和 Setup/Hold 数量会在操作前提示。依赖被删通道的 Derived Signal 会保留并显示缺失来源错误。

## 展示与 Timing

点击 Bus 属性栏的 **Signal manager**，可直接在管理器切换 **Fold / Select / All**。也可从画布工具栏的 **Signals** 打开管理器，点击 Bus 行的通道图标。新建时默认全部展开，只有用户主动选择精选或折叠才会收起通道；从标题按钮折叠再展开时恢复之前的展开模式。折叠仅占一行；精选可输入 `0–3, 38–39`，也可选前四路、奇数路或偶数路，并显示未展示数量。折叠和隐藏只改变视图，所有通道继续参加 Timing 计算。Bus 汇总行使用带双轨细节的波形段，按实际时间切换。连续编号时显示如 `D0–D39`、`D40–D79`；其他排列在宽度足够时列出完整序列，空间不足时显示开头与结尾的若干数据项，中间用省略号连接。悬停可查看按通道排列的完整标签。通道尚未全部开始时附带已开始/总通道数，避免误认为所有通道都有值。局部 Start、间隔和 Delay 造成的切换也会反映在汇总行。点击标题编辑 Bus，点击子通道名编辑该 Data Signal。波形区域仍用于拖动平移。

Bus 可整体排序、复制、隐藏、删除；普通 Signal 分组也可包含 Bus。复制后通道获得新 ID，Bus 内部引用改指向副本，指向外部 Signal 的来源保持不变。选中 Bus 标题，可在 Timing relationships 的 Setup / hold constraint 区域创建共享约束。它按每路的实际边沿分别检查，在 Bus 汇总行标出任一路发生的违例；隐藏、折叠与新增通道也遵循同一条规则。子通道仍可独立设置约束。

工程 JSON 在现有 v3 Schema 下增加可选 `buses[]`，子通道仍位于 `signals[]` 并通过 `busId`、`busIndex` 关联。旧工程没有 `buses[]` 时按空集合读取，旧 Data 保持独立。SVG 按当前显示行导出，包括 Bus 摘要、展开的子通道、Clock 和可见 Timing 图形。

### 混合区与逐路偏移

在 Bus 属性中设置 Maximum advance 和 Maximum delay（ps）。Bus 汇总行用斜纹表示从最早可能换拍到最晚可能换拍的区间，包括各路的 Start 和已解析的 Delay。只在相同数据间隔的通道之间按槽序号比较；不同间隔组各自计算后合并展示。折叠和隐藏不影响计算。

选择子通道并启用 Fixed channel offset，可用负数提前、正数延后。固定偏移取代该通道的 Bus 范围，在已有 Delay 的基础上移动实际波形。取消勾选即可恢复继承。Bus 范围表示不确定性；Setup/Hold 仍由现有约束针对实际边沿计算，无约束时只展示混合区。


### 从输入总线创建派生总线

工程中至少有一条 Bus 和一个 Clock 时，选择 **Add → Derived Bus**。指定输入 Bus、Clock、输出名称及 DFF 或 Latch 的采样条件，设置传播延迟，然后选择 **Add**。输出与输入同宽，第 i 路输出采样第 i 路输入，得到该通道的数据项标签。创建后每路可单独调整。

折叠或隐藏输入 Bus 不影响采样。手动删除或缩窄输入 Bus 后，受影响的输出路会保留并提示来源缺失；通过 MCP 修改时，必须在同一批操作中处理这些引用。

各路可以有不同的 Start、间隔、固定 skew 或 Delay，所以采样以各路实际边沿为准。即使显示编号不同，输入和输出也按内部通道序号一一对应，不进行截断或扩展。

### 显示状态

包含 `X` 的稳定段使用交叉纹理及 `X` 标签，与灰色斜纹的换拍混合区区分。混合区内以淡虚线标出已知通道边沿；Bus 的主体颜色跟随波形调色板，标签字号跟随 Data 标签设置。


### 批量派生接口

[MCP 写入接口](AGENT_API.md#写入)提供原子操作 `create_derived_bus`。调用方指定输出 Bus 的 ID 和名称、输入 Bus ID、Clock ID、器件类型与触发条件、共享的 C2Q（Latch 还需 D2Q）及初值。初版要求输入输出同宽，按照内部 `busIndex` 一一对应，而不是按显示编号猜测映射。服务端一次创建输出 Bus 与所有 Derived Data 通道；任一路来源、时钟、延迟或信号数量不合法时整次回滚。输出通道获得独立 ID，后续可逐路编辑 derivation。

输出 Bus 汇总行读取每路已解析的 Q 波形。Q 的 C→Q 延迟范围仍参与 Timing 计算，但不再在汇总行画成短暂的灰色混合段。DFF 若在输入 Bus 混合区内采样，Q 保留按当前边沿计算的值；存在 bit 错位风险时，汇总行的整条 Q 波形绘制区显示连续的淡黄色外框，不按采样时间切段，也不遮盖左侧信号名称。展开后，只有受影响的子通道显示同义外框。外框颜色随亮暗主题和波形调色板切换；悬停可查看采样时间和原因。已有直接 Setup/Hold 红色违例时不叠加黄色提示，MCP `uncertainSamples` 数据保持不变。Latch 仍沿用单路透明窗口模型；当前没有把输入可能换拍范围传播到透明期内的每一次 D→Q 变化，因此这类不确定性还需要单独设计。输出 Bus 宽度与输入一一对应，当前禁止直接扩缩容；逐路 derivation 可独立编辑。

有 bit 错位风险的输出 Bus 及受影响的子通道，会在信号名称右侧显示黄色 warning 图标；悬停提示 `Bit misalignment risk`。
